# Imágenes fijas del sitio

El logo ya está en `public/logo.jpg`. Para cambiarlo, reemplazá ese archivo
(también sirve `public/logo.png`) y, si querés que cambie el ícono de la pestaña
del navegador, la misma imagen va en `app/icon.jpg`.

Se muestra en el círculo de la portada (recortado en círculo, así que conviene
que el motivo esté centrado). Si no hay ningún archivo, la web dibuja la pestaña
vectorial de reemplazo, no se rompe nada.

Para que Vercel lo tome: commit + push del archivo (o subirlo desde GitHub web).

Las fotos de los **productos** no van acá: esas se suben desde el panel.
